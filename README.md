# C++ Electrical Engineering Tools

A collection of C++ command-line utilities and practice scripts built for electrical engineering calculations and coursework.

## Included Scripts
* **`ohmlawtoolkit.cpp`** – Calculates voltage, current, and resistance using Ohm's Law.
* **`power.cpp`** – Computes electrical power dissipation.
* **`printSystemStatuys.cpp`** – Displays formatted system status outputs.
* **`setfillString.cpp`** – Demonstrates string and console output formatting.
* **`Challenge.cpp`** – Engineering problem-solving exercise.

## How to Run
Compile any script using `g++` in your terminal:
```bash
g++ ohmlawtoolkit.cpp -o app
./app
```
